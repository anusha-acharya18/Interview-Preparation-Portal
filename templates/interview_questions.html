💻 C Programming Interview Questions

Basic Concept

Q1. What is C programming language?

Answer: C is a general-purpose, procedural programming language developed by Dennis Ritchie.

📖 Read More

C is widely used for system programming, operating systems and embedded applications. It provides features such as pointers, functions and structured programming.

Basic Concept

Q2. What is the difference between a compiler and an interpreter?

Answer: A compiler translates source code into machine code before execution, while an interpreter executes instructions through an interpretation process.

📖 Read More

A compiler generally translates a program before it runs. An interpreter processes the program during execution. C commonly uses a compiler.

Important Concept

Q3. What is a pointer in C?

Answer: A pointer is a variable that stores the memory address of another variable.

📖 Read More

Pointers are useful for dynamic memory allocation, arrays, functions and efficient memory handling. The address-of operator (&) obtains an address, while the dereference operator (*) accesses the value stored at that address.

Frequently Asked

Q4. What is the difference between = and == in C?

Answer: The = operator assigns a value, whereas == compares two values.

📖 Read More

For example, x = 10 assigns 10 to x. The expression x == 10 checks whether x is equal to 10 and returns true or false.

Important Concept

Q5. What is the difference between an array and a pointer?

Answer: An array stores a collection of elements, while a pointer stores a memory address.

📖 Read More

An array has a fixed size after declaration. A pointer can be reassigned to point to different memory locations. Although array names often convert to pointers, arrays and pointers are not the same thing.

Memory Management

Q6. What is dynamic memory allocation in C?

Answer: Dynamic memory allocation means allocating memory during program execution.

📖 Read More

C provides functions such as malloc(), calloc(), realloc() and free() for dynamic memory management. These functions are declared in the stdlib.h header file.

Frequently Asked

Q7. What is the difference between malloc() and calloc()?

Answer: malloc() allocates a block of memory without initializing it, while calloc() allocates memory for multiple elements and initializes it to zero.

📖 Read More

Both functions return a pointer to the allocated memory. The programmer should check whether the returned pointer is NULL before using the memory.

Output-Based Question

Q8. What is the output of the following C statement?

Code: printf("%d", 5 + 3 * 2);

Answer: 11

📖 Read More

Multiplication has higher precedence than addition. Therefore, 3 * 2 is evaluated first, giving 6. Then 5 + 6 gives 11.

Important Concept

Q9. What is recursion in C?

Answer: Recursion is a process in which a function calls itself.

📖 Read More

A recursive function must have a base condition to stop repeated calls. Recursion is commonly used in factorial calculations, tree traversal and mathematical problems.

Frequently Asked

Q10. What is the difference between break and continue?

Answer: break terminates the loop, whereas continue skips the current iteration.

📖 Read More

The break statement transfers control outside the loop. The continue statement skips the remaining statements in the current iteration and proceeds to the next iteration.

Basic Concept

Q11. What is the difference between local and global variables?

Answer: A local variable is declared inside a function or block, while a global variable is declared outside all functions.

📖 Read More

A local variable can generally be accessed only within its declared scope. A global variable can be accessed by functions in the same file, subject to its scope and linkage.

Pointer Concept

Q12. What is a NULL pointer?

Answer: A NULL pointer is a pointer that does not point to a valid object or function.

📖 Read More

NULL is commonly used to indicate that a pointer has no valid target. A program should not dereference a NULL pointer because doing so causes undefined behavior.

Storage Class

Q13. What is the use of the static keyword in C?

Answer: The static keyword controls the lifetime or visibility of variables and functions.

📖 Read More

A static local variable retains its value between function calls. A static global variable or function has internal linkage, meaning it is limited to the current source file.

Important Concept

Q14. What is a structure in C?

Answer: A structure is a user-defined data type that groups variables of different data types under one name.

📖 Read More

A structure is declared using the struct keyword. It is useful for representing related information, such as a student's name, roll number and marks.

Frequently Asked

Q15. What is the difference between a structure and a union?

Answer: A structure gives separate storage to its members, whereas union members share the same memory location.

📖 Read More

In a structure, multiple members can hold values at the same time. In a union, storing a value in one member affects the shared storage used by the other members.

Storage Classes

Q16. What are storage classes in C?

Answer: Storage classes define the scope, lifetime and visibility of variables.

📖 Read More

The main storage class specifiers are auto, register, static and extern. They determine how variables are stored and accessed in a program.

Frequently Asked

Q17. What is the difference between call by value and call by reference?

Answer: Call by value passes a copy of a value, while passing a pointer allows a function to modify the original variable.

📖 Read More

C uses call by value. Reference-like behavior can be achieved by passing the address of a variable through a pointer. Changes made through that pointer can affect the original variable.

String Concept

Q18. What is a string in C?

Answer: A string is an array of characters terminated by the null character '\0'.

📖 Read More

Strings are used to store text. Common string functions such as strlen(), strcpy(), strcat() and strcmp() are available through string.h.

Frequently Asked

Q19. What is the difference between strlen() and sizeof()?

Answer: strlen() returns the number of characters in a string before '\0', while sizeof() returns the size in bytes of an object or type.

📖 Read More

For example, for char name[] = "Hello", strlen(name) returns 5, whereas sizeof(name) returns 6 because it includes the null terminator.

Pointer Concept

Q20. What is a void pointer in C?

Answer: A void pointer is a generic pointer that can hold the address of an object of any data type.

📖 Read More

A void pointer can store different object addresses. It must be converted to an appropriate pointer type before dereferencing in standard C.

Pointer Concept

Q21. What is a dangling pointer?

Answer: A dangling pointer refers to memory that is no longer valid for use.

📖 Read More

It may occur when memory is freed or when a pointer refers to a local variable whose lifetime has ended. Using a dangling pointer can cause undefined behavior.

Memory Management

Q22. What is a memory leak in C?

Answer: A memory leak occurs when dynamically allocated memory is no longer needed but is not released.

📖 Read More

Memory allocated using malloc() or calloc() should be released using free() when it is no longer required. Unreleased memory can increase a program's memory usage.

Memory Management

Q23. Explain malloc(), calloc(), realloc() and free().

Answer: These functions are used for dynamic memory allocation and deallocation in C.

📖 Read More

malloc() allocates uninitialized memory. calloc() allocates zero-initialized memory. realloc() changes the size of an allocated block. free() releases dynamically allocated memory.

Functions

Q24. What is a function prototype in C?

Answer: A function prototype declares a function's name, return type and parameter types before it is used.

📖 Read More

It helps the compiler check whether a function is called with the correct arguments and return type. Example: int add(int, int);

Preprocessor

Q25. What is a macro in C?

Answer: A macro is a name or code fragment defined using the #define preprocessor directive.

📖 Read More

Macros are processed before compilation. They are commonly used for symbolic constants and simple code substitutions. Example: #define PI 3.14

Header Files

Q26. What is the difference between #include <file.h> and #include "file.h"?

Answer: Angle brackets are generally used for system headers, while quotation marks are generally used for local headers.

📖 Read More

The compiler searches for headers according to its configured include search paths. Quoted includes generally search the current source file's directory first.

Output-Based Question

Q27. What is the output of the following code?

Code: int x = 10; printf("%d", x++);

Answer: 10

📖 Read More

The post-increment operator uses the current value first and increments the variable afterward. Therefore, the printed value is 10 and x becomes 11.

Output-Based Question

Q28. What is the output of the following code?

Code: int x = 10; printf("%d", ++x);

Answer: 11

📖 Read More

The pre-increment operator increases the value before it is used. Therefore, x becomes 11 and 11 is printed.

Frequently Asked

Q29. What is the difference between i++ and ++i?

Answer: i++ is post-increment, while ++i is pre-increment.

📖 Read More

Post-increment uses the original value before increasing it. Pre-increment increases the value first and then uses the updated value.

Data Types

Q30. What is an enum in C?

Answer: An enum is a user-defined data type consisting of named integer constants.

📖 Read More

The enum keyword makes programs easier to read by assigning names to related integer values. Example: enum Day {MON, TUE, WED};

Important Concept

Q31. Can a union contain different data types?

Answer: Yes. A union can contain members of different data types, but all members share the same memory.

📖 Read More

The size of a union is sufficient to hold its largest member, including any alignment requirements. Typically, only one member's stored value is used at a time.

Important Concept

Q32. What is undefined behavior in C?

Answer: Undefined behavior means the C standard does not specify what happens when a particular operation is performed.

📖 Read More

Examples include accessing an array outside its bounds and dereferencing an invalid pointer. The program may behave unpredictably, so such operations must be avoided.

Keywords

Q33. What is the use of the const keyword in C?

Answer: The const keyword declares an object whose value cannot be modified through that const-qualified name.

📖 Read More

It helps protect values from accidental modification. Example: const int age = 20;

Advanced Concept

Q34. What is a function pointer in C?

Answer: A function pointer is a pointer that stores the address of a function.

📖 Read More

Function pointers allow functions to be called indirectly. They are useful for callback functions, menu-driven programs and flexible program design.

Memory Management

Q35. What is the difference between stack and heap memory?

Answer: Stack memory is commonly used for function calls and automatic local variables, while heap memory is used for dynamic memory allocation.

📖 Read More

Stack memory is managed automatically during function execution. Heap memory is managed through functions such as malloc() and free().

Coding Question

Q36. How can you reverse a string in C?

Answer: A string can be reversed by swapping characters from the beginning and end until the middle is reached.

📖 Read More

First find the string length. Then use two positions, one at the beginning and one at the end. Swap the characters and move both positions toward the center.

Coding Question

Q37. How do you check whether a number is prime in C?

Answer: A number is prime if it is greater than 1 and has exactly two positive factors: 1 and itself.

📖 Read More

Check whether the number is divisible by any integer from 2 up to its square root. If no divisor is found, the number is prime.

Output-Based Question

Q38. What is the output of the following expression?

Code: printf("%d", 10 / 3);

Answer: 3

📖 Read More

Both operands are integers, so integer division is performed. The fractional part is discarded, giving 3.

Header Files

Q39. What is a header file in C?

Answer: A header file contains declarations, macros and other information that can be shared between source files.

📖 Read More

Header files usually have the .h extension. Examples include stdio.h for input and output declarations and string.h for string functions.

Frequently Asked

Q40. What is the difference between a syntax error and a runtime error?

Answer: A syntax error occurs when code violates language rules, while a runtime error occurs during program execution.

📖 Read More

A missing semicolon can cause a syntax error. An attempt to divide an integer by zero can cause a runtime error on common C implementations.

🐍 Python Programming Interview Questions

Basic Concept

Q41. What is Python?

Answer: Python is a high-level, interpreted, general-purpose programming language.

📖 Read More

Python is known for its simple syntax and readability. It is used in web development, automation, data science, artificial intelligence and scripting.

Frequently Asked

Q42. What are the main features of Python?

Answer: Simple syntax, interpreted execution, dynamic typing, portability and a large standard library.

📖 Read More

Python supports multiple programming styles and provides many built-in functions. Its libraries make development easier and faster.

Important Concept

Q43. Is Python compiled or interpreted?

Answer: Python uses both compilation and interpretation.

📖 Read More

In standard Python implementations, source code is first compiled into bytecode. The Python virtual machine then executes that bytecode.

Frequently Asked

Q44. What is the difference between a list and a tuple?

Answer: A list is mutable, whereas a tuple is immutable.

📖 Read More

Lists use square brackets and allow modification after creation. Tuples use parentheses and their elements cannot be reassigned after creation.

Important Concept

Q45. What is the difference between == and is in Python?

Answer: == compares values, while is checks object identity.

📖 Read More

The equality operator checks whether two objects contain equal values. The identity operator checks whether both references point to the same object.

Basic Concept

Q46. What are the basic data types in Python?

Answer: int, float, complex, str, bool, list, tuple, set and dict.

📖 Read More

Python provides different data types to store numbers, text and collections. The type() function can be used to identify an object's data type.

Important Concept

Q47. What is a dictionary in Python?

Answer: A dictionary stores data in key-value pairs.

📖 Read More

Dictionaries are written using curly braces. Each key is unique, and values can be accessed using their corresponding keys.

Frequently Asked

Q48. What is the difference between a set and a list?

Answer: A list allows duplicate elements, while a set stores unique elements.

📖 Read More

Lists maintain element order and support indexing. Sets do not support positional indexing and are useful for removing duplicates.

Functions

Q49. What is a function in Python?

Answer: A function is a reusable block of code that performs a specific task.

📖 Read More

Functions are defined using the def keyword. They can accept arguments and return results using the return statement.

Frequently Asked

Q50. What is the difference between break, continue and pass?

Answer: break terminates a loop, continue skips the current iteration, and pass does nothing.

📖 Read More

These statements control program execution. break exits the loop completely, continue moves to the next iteration, and pass acts as a placeholder.

OOP Concept

Q51. What is a class in Python?

Answer: A class is a blueprint used to create objects.

📖 Read More

A class defines attributes and methods. It helps organize related data and functions into a single structure.

OOP Concept

Q52. What is an object in Python?

Answer: An object is an instance of a class.

📖 Read More

An object has its own data and can use the methods defined by its class. Multiple objects can be created from one class.

OOP Concept

Q53. What is the __init__() method?

Answer: It is a special method that initializes an object's attributes when the object is created.

📖 Read More

The __init__() method is commonly called a constructor. It runs automatically when a new object is instantiated.

Output-Based Question

Q54. What is the output of the following Python code?

Code: print(2 ** 3)

Answer: 8

📖 Read More

The ** operator performs exponentiation. Therefore, 2 ** 3 means 2 multiplied by itself three times, which gives 8.

Important Concept

Q55. What is the difference between mutable and immutable objects?

Answer: Mutable objects can be changed after creation, whereas immutable objects cannot be changed.

📖 Read More

Lists, dictionaries and sets are mutable. Integers, strings and tuples are examples of immutable objects.

Frequently Asked

Q56. What is indentation in Python?

Answer: Indentation refers to the spaces at the beginning of a code line used to define a block of code.

📖 Read More

Python uses indentation instead of braces to identify blocks inside functions, loops and conditional statements. Incorrect indentation can cause an IndentationError.

Basic Concept

Q57. What is the difference between a variable and a constant in Python?

Answer: A variable can be reassigned, while a constant represents a value intended not to change.

📖 Read More

Python does not enforce constants directly. By convention, constant names are written in uppercase, such as MAX_SIZE = 100.

Frequently Asked

Q58. What is the difference between append() and extend()?

Answer: append() adds one item to a list, while extend() adds elements from an iterable.

📖 Read More

If [1, 2] is extended with [3, 4], the result is [1, 2, 3, 4]. Using append([3, 4]) instead adds the entire list as one nested element.

Output-Based Question

Q59. What is the output of this code?

Code: print(10 // 3)

Answer: 3

📖 Read More

The // operator performs floor division. It returns the quotient rounded down to the nearest integer for positive operands in this example.

Output-Based Question

Q60. What is the output of this code?

Code: print("Python" * 2)

Answer: PythonPython

📖 Read More

The multiplication operator repeats a string the specified number of times. Here, the word Python is repeated twice.

Functions

Q61. What are lambda functions in Python?

Answer: A lambda function is a small anonymous function defined using the lambda keyword.

📖 Read More

Lambda functions can contain a single expression. Example: square = lambda x: x * x. Calling square(5) returns 25.

Functions

Q62. What is the difference between arguments and parameters?

Answer: Parameters are variables in a function definition, while arguments are values passed when calling the function.

📖 Read More

In def add(a, b), a and b are parameters. In add(5, 3), the values 5 and 3 are arguments.

Important Concept

Q63. What is exception handling in Python?

Answer: Exception handling is a mechanism used to handle runtime errors without abruptly stopping normal program flow.

📖 Read More

Python uses try, except, else and finally blocks. They help detect errors, handle exceptions and perform cleanup operations.

Frequently Asked

Q64. What is the difference between a syntax error and an exception?

Answer: A syntax error occurs when code violates Python's grammar, while an exception is an error detected during execution.

📖 Read More

A missing colon after an if statement can cause a SyntaxError. Dividing an integer by zero raises a ZeroDivisionError during execution.

File Handling

Q65. How do you open a file in Python?

Answer: The open() function is used to open a file in Python.

📖 Read More

Common file modes include r for reading, w for writing, a for appending and b for binary mode. The with statement helps close files automatically.

File Handling

Q66. What is the difference between read(), readline() and readlines()?

Answer: read() reads file content, readline() reads one line, and readlines() returns all lines as a list.

📖 Read More

These methods are available on file objects. The appropriate method depends on whether the program needs the whole file, one line or a list of lines.

Modules

Q67. What is a module in Python?

Answer: A module is a Python file containing functions, variables and classes that can be reused in other programs.

📖 Read More

Modules help organize code into separate files. They can be included using the import statement. Examples include math, random and datetime.

Modules

Q68. What is a package in Python?

Answer: A package is a way to organize related Python modules into a directory structure.

📖 Read More

Packages help organize large applications into manageable components. They allow related modules to be grouped under a common namespace.

OOP Concept

Q69. What is inheritance in Python?

Answer: Inheritance allows one class to acquire properties and methods from another class.

📖 Read More

The existing class is called the parent or base class, while the new class is called the child or derived class. Inheritance supports code reuse.

OOP Concept

Q70. What is polymorphism in Python?

Answer: Polymorphism allows the same interface or operation to work with objects of different types.

📖 Read More

For example, the len() function can work with strings, lists and tuples. Each object type provides its own behavior for the operation.

OOP Concept

Q71. What is encapsulation in Python?

Answer: Encapsulation is the practice of combining data and methods within a class and controlling access to them.

📖 Read More

Python uses naming conventions and properties to manage attribute access. A double underscore prefix triggers name mangling, but it does not provide strict privacy.

Important Concept

Q72. What is list comprehension in Python?

Answer: List comprehension is a concise way to create a list from an iterable.

📖 Read More

Example: squares = [x*x for x in range(5)]. This creates a list containing the squares of numbers from 0 to 4.

Output-Based Question

Q73. What is the output of this code?

Code: print(len([10, 20, 30, 40]))

Answer: 4

📖 Read More

The len() function returns the number of elements in a collection. This list contains four elements, so the output is 4.

Important Concept

Q74. What is the difference between shallow copy and deep copy?

Answer: A shallow copy creates a new outer object but shares references to nested objects, while a deep copy recursively copies nested objects.

📖 Read More

The copy module provides copy.copy() for shallow copying and copy.deepcopy() for deep copying. Deep copying is useful when nested mutable objects must be independent.

Frequently Asked

Q75. What is PEP 8 in Python?

Answer: PEP 8 is the official style guide for writing readable Python code.

📖 Read More

It provides recommendations for indentation, naming conventions, spacing and code formatting. Following PEP 8 makes code easier to read and maintain.

☕ Java Programming Interview Questions

Basic Concept

Q76. What is Java?

Answer: Java is a high-level, class-based, object-oriented programming language.

📖 Read More

Java is widely used for enterprise applications, web development and Android development. It is designed to be portable across supported platforms using the Java Virtual Machine.

Frequently Asked

Q77. What are the main features of Java?

Answer: Object-oriented, platform-independent, secure, robust, portable and multithreaded.

📖 Read More

Java provides automatic memory management, exception handling and a rich standard library. These features support the development of reliable applications.

Important Concept

Q78. Why is Java called platform-independent?

Answer: Java programs are compiled into bytecode that can run on different platforms with a compatible JVM.

📖 Read More

The Java compiler produces bytecode rather than platform-specific machine code. The Java Virtual Machine executes this bytecode on the target system.

Frequently Asked

Q79. What is JVM?

Answer: JVM stands for Java Virtual Machine. It executes Java bytecode.

📖 Read More

The JVM loads and verifies classes, manages memory and executes bytecode. It provides the runtime environment for Java applications.

Frequently Asked

Q80. What is the difference between JDK, JRE and JVM?

Answer: JDK provides development tools, JRE provides the runtime environment, and JVM executes bytecode.

📖 Read More

The JDK includes tools such as the Java compiler. The JRE traditionally includes the JVM and libraries needed to run Java applications.

OOP Concept

Q81. What is a class in Java?

Answer: A class is a blueprint that defines the data and behavior of objects.

📖 Read More

A class contains fields, constructors and methods. Objects are created from classes using the new keyword.

OOP Concept

Q82. What is an object in Java?

Answer: An object is an instance of a class.

📖 Read More

An object has state represented by fields and behavior represented by methods. Multiple objects can be created from the same class.

OOP Concept

Q83. What are the four pillars of OOP?

Answer: Encapsulation, inheritance, polymorphism and abstraction.

📖 Read More

Encapsulation protects and organizes data, inheritance supports code reuse, polymorphism allows different behaviors through a common interface, and abstraction hides implementation details.

Constructors

Q84. What is a constructor in Java?

Answer: A constructor is a special class member used to initialize objects.

📖 Read More

A constructor has the same name as its class and does not have a return type. It is invoked when an object is created.

Frequently Asked

Q85. What is the difference between a constructor and a method?

Answer: A constructor initializes an object, while a method performs a specific operation.

📖 Read More

Constructors have the same name as the class and no return type. Methods can have any valid name and may return a value or void.

Frequently Asked

Q86. What is method overloading?

Answer: Method overloading means defining multiple methods with the same name but different parameter lists.

📖 Read More

Overloaded methods can differ in the number, types or order of parameters. Return type alone cannot distinguish overloaded methods.

OOP Concept

Q87. What is method overriding?

Answer: Method overriding occurs when a subclass provides its own implementation of an inherited method.

📖 Read More

Overriding supports runtime polymorphism. The method that runs depends on the actual object involved in the method call.

Frequently Asked

Q88. What is the difference between overloading and overriding?

Answer: Overloading uses the same method name with different parameters, while overriding redefines an inherited method in a subclass.

📖 Read More

Overloading is resolved using the method signature at compile time. Overriding enables runtime method dispatch for instance methods.

OOP Concept

Q89. What is inheritance in Java?

Answer: Inheritance allows a class to acquire accessible properties and methods from another class.

📖 Read More

Java uses the extends keyword for class inheritance. It helps reuse existing code and establish relationships between classes.

Important Concept

Q90. Does Java support multiple inheritance?

Answer: Java does not support multiple inheritance through classes, but a class can implement multiple interfaces.

📖 Read More

This design avoids certain ambiguities associated with inheriting implementation from multiple classes. Interfaces provide a way to support multiple types.

Keywords

Q91. What is the use of the this keyword in Java?

Answer: The this keyword refers to the current object.

📖 Read More

It is commonly used to distinguish instance variables from parameters with the same name. It can also call another constructor in the same class.

Keywords

Q92. What is the use of the super keyword?

Answer: The super keyword refers to the immediate parent class.

📖 Read More

It can access accessible parent class members and invoke a parent class constructor. A call to super() must be the first statement in a constructor when used explicitly.

Frequently Asked

Q93. What is the difference between == and equals() in Java?

Answer: == compares primitive values or object references, while equals() checks logical equality when appropriately implemented by a class.

📖 Read More

For objects, == checks whether two references point to the same object. The equals() method can compare the contents of objects, as String does.

Strings

Q94. Why is String immutable in Java?

Answer: String objects cannot be changed after they are created.

📖 Read More

Immutability supports safe sharing, predictable behavior and efficient string pooling. Operations that appear to modify a String create a new String object.

Strings

Q95. What is the difference between String, StringBuilder and StringBuffer?

Answer: String is immutable, StringBuilder is mutable and not synchronized, while StringBuffer is mutable and synchronized.

📖 Read More

StringBuilder is generally preferred for repeated string modifications in single-threaded code. StringBuffer provides synchronized methods for thread-safe operations.

Keywords

Q96. What is the use of the static keyword in Java?

Answer: The static keyword makes a member belong to the class rather than to individual objects.

📖 Read More

Static variables are shared by instances of the class. Static methods can be called using the class name without creating an object.

Keywords

Q97. What is the use of the final keyword in Java?

Answer: final can prevent reassignment of variables, overriding of methods and inheritance of classes.

📖 Read More

A final variable can be assigned only once. A final method cannot be overridden, and a final class cannot be extended.

Exception Handling

Q98. What is exception handling in Java?

Answer: Exception handling is a mechanism for handling abnormal conditions during program execution.

📖 Read More

Java provides try, catch, finally, throw and throws for exception handling. It helps programs respond to errors in a controlled way.

Exception Handling

Q99. What is the difference between checked and unchecked exceptions?

Answer: Checked exceptions are checked by the compiler, while unchecked exceptions are not required to be declared or caught by the compiler.

📖 Read More

IOException is an example of a checked exception. NullPointerException and ArithmeticException are examples of unchecked exceptions.

Output-Based Question

Q100. What is the output of the following Java code?

Code: System.out.println(10 + 20 + "Java");

Answer: 30Java

📖 Read More

Java evaluates the expression from left to right. First, 10 + 20 produces 30. Then string concatenation produces 30Java.

🌐 Computer Networks Interview Questions

Q236. What is a computer network?

Answer: A computer network is a group of interconnected computers and devices that communicate and share data and resources.

Explanation: Networks allow users to exchange information, share files, and access shared resources.

Q237. What are the main types of computer networks?

Answer: PAN, LAN, MAN, and WAN.

Explanation: These networks are classified based on the geographical area they cover.

Q238. What is LAN?

Answer: LAN stands for Local Area Network. It connects devices within a small geographical area.

Explanation: Homes, schools, offices, and laboratories commonly use LANs.

Q239. What is WAN?

Answer: WAN stands for Wide Area Network. It connects devices over large geographical areas.

Explanation: The Internet is the largest example of a WAN.

Q240. What is MAN?

Answer: MAN stands for Metropolitan Area Network. It connects networks across a city or large campus.

Explanation: It covers a larger area than LAN but a smaller area than WAN.

Q241. What is network topology?

Answer: Network topology is the physical or logical arrangement of devices in a network.

Explanation: Common topologies include bus, star, ring, mesh, and tree.

Q242. What is the OSI model?

Answer: The OSI model is a seven-layer reference model used to understand network communication.

Explanation: Its seven layers are Physical, Data Link, Network, Transport, Session, Presentation, and Application.

Q243. Name the seven layers of the OSI model.

Answer: Physical, Data Link, Network, Transport, Session, Presentation, and Application.

Explanation: Each layer performs a specific function during data communication.

Q244. What is the TCP/IP model?

Answer: The TCP/IP model is a networking framework used for communication over the Internet.

Explanation: It commonly consists of four layers: Network Access, Internet, Transport, and Application.

Q245. What is an IP address?

Answer: An IP address is a unique logical address assigned to a device on an IP network.

Explanation: It helps identify devices and route data to the correct destination.

Explanation: These functions help the computer run programs and manage resources efficiently.

Q264. What is a process?

Answer: A thread is the smallest unit of execution within a process.

Q266. What is the difference between a process and a thread?

Answer: A process is an independent executing program, while a thread is a smaller execution unit within a process.

Explanation: Processes generally have separate memory spaces, while threads of the same process share memory.

Q267. What is multitasking?

Answer: Multitasking is the ability of an operating system to run multiple tasks seemingly at the same time.

Explanation: The operating system manages CPU time among different tasks.

Q268. What is multiprocessing?

Answer: Multiprocessing is the use of two or more processors or CPU cores to execute tasks.

Explanation: It can improve performance by allowing tasks to run in parallel.

Q269. What is context switching?

Answer: Context switching is the process of saving the state of one process or thread and loading another.

Explanation: It allows the CPU to switch between different tasks.

Q270. What is CPU scheduling?

Answer: CPU scheduling is the method used by an operating system to select which process gets CPU time.

Explanation: It helps manage processes and improve CPU utilization.

Q271. Name some CPU scheduling algorithms.

Explanation: Each algorithm uses a different method to decide the order of process execution.

Q272. What is deadlock?

Explanation: As a result, the processes cannot continue their execution.

Explanation: All four conditions must be present simultaneously for a deadlock to occur.

Q274. What is memory management?

Q275. What is virtual memory?

Explanation: It allows programs to operate even when physical RAM is limited.

Q276. What is paging?

Answer: Paging is a memory management technique that divides virtual memory into fixed-size pages and physical memory into frames.

Explanation: Pages can be placed in available frames, helping manage memory efficiently.

Q277. What is segmentation?

Answer: Segmentation is a memory management technique that divides a program into variable-sized logical segments.

Explanation: Examples include code, data, and stack segments.

Q278. What is fragmentation?

Answer: Fragmentation is the wastage of memory space caused by inefficient memory allocation.

Explanation: It is mainly classified into internal and external fragmentation.

Q279. What is a semaphore?

Answer: A semaphore is a synchronization mechanism used to control access to shared resources.

Explanation: It helps coordinate processes and threads and prevent certain race conditions.

Q280. What is a race condition?

Answer: A race condition occurs when the result of a program depends on the timing or order of concurrent operations.

Explanation: It can happen when multiple threads access shared data without proper synchronization.
